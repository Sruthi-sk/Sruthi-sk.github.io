# Sruthi-sk.github.io

Personal website with multiple sections showcasing professional portfolio, projects, publications, blogs, and more.

## Features

- **About**: Personal introduction and background
- **Projects**: Showcase of work and technical projects
- **Publications**: Research papers and academic contributions
- **Blogs**: Technical writings and personal insights
- **Others**: Awards, skills, and additional information

## Structure

- `index.html` - Main website structure
- `style.css` - Responsive styling and design
- `script.js` - Interactive functionality and animations

## Customization

To customize the website with your own content:

1. Edit `index.html` to update text content in each section
2. Modify colors and styling in `style.css` by changing CSS variables
3. Add your own images and links as needed

## Technologies Used

- HTML5
- CSS3 (with CSS Grid and Flexbox)
- Vanilla JavaScript
- Responsive design for mobile and desktop
